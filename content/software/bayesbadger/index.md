BayesBadger is an R package for a Bayesian BetA Double GEneralized Regression with mean modeled using individual-level covariates and precision modeled through cluster-level covariates. The model also allows for spatial smoothing through a graph Laplacian prior. A vignette with instructions on how to use the package can be found [here](https://htmlpreview.github.io/?https://github.com/abhijainstats/BayesBadger/blob/main/vignettes/BayesBadger_vignette.html) and source code can be found on the [Github repository](https://github.com/abhijainstats/BayesBadger).
